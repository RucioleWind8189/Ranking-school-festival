# 学科開放用タイムアタックのランキングアプリ

## 概要

このプロジェクトは、学祭でタイムアタックゲームをした際のランキングを表示するものです。  

## インストール  

そんなものは必要ない。なぜならHTMLふぁいるにすべてまとめてあるからだ。
Cromeブラウザを使ってくれると嬉しい。
  
## 使い方

1. [プレイヤー名とタイムを手動で入力します。]
2. [上位5位までの名前とタイム、平均と最速記録が表示されます。]
3. [CSVファイルで入力されたログを取ることができます。]

## 技術的な部分  

ReactとTailwindCSSを使用しています。  
*ChatGPT-5を使用しています。*
